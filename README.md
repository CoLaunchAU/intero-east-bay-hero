# Intero East Bay hero prototype

A static navigation and hero demo, with the supplied Intero logo and a luxury Pleasanton estate exterior.

The site contains only the navigation and hero. Text, controls, image and overlays are separate editable elements.

## Portable files

- [Standalone HTML](downloads/intero-hero.html): includes the photo, logo, fonts, CSS and JavaScript in one file; works offline.
- [Static ZIP](downloads/intero-hero-static.zip): upload-ready HTML, CSS, JavaScript and assets.

For Figma, import the HTML or ZIP using html.to.design's File tab at a 2192 × 1162 viewport.

See [asset sources](ASSET-SOURCES.md) for image attribution and font provenance. This is a design prototype.
